这里推荐两项服务：XMRth 机场和 PackyAPI 大模型 API 中转站，文中附有推广链接。价格、套餐和优惠都是此前记录的信息，注册或付款前，请以服务商当前页面和结算页为准。

代理网络服务通常被称为“机场”，主要提供网络连接线路。API 中转服务则接收应用发来的模型调用请求，再转发给相应渠道。两者用途不同；购买 API 调用额度，也不包含 ChatGPT 或 Claude 的官方网页会员。

**中继、IPLC 和节点分别是什么：**

- 中继通常指经中间服务器或线路转发流量；这里的具体路径和流量扣除方式，应查服务商套餐说明。
- IPLC 是 International Private Leased Circuit，即国际私有租用线路。套餐标注“专线”或“IPLC”时，仍需核对其完整网络路径、出口 IP 类型和实际速度，仅凭名称无法确认这些信息。
- 节点是客户端中可选择的连接入口。即使节点标注了某个地区，能否访问目标服务仍受该平台的地区限制、账号状态和服务规则影响。

**当时套餐列出的功能：**

- 美港节点及 IPLC 线路；曾列出 ChatGPT、Claude、Gemini 的访问支持
- Netflix、YouTube、Disney+ 等流媒体访问支持
- 标注速率 300–1000 Mbps，最多 8 台设备同时在线

上面的速率是历史标注，不是实测下载速度；设备数、流量及平台支持情况需要购买前确认。付费线路也不能保证免于平台风控。

### 二、PackyAPI 大模型 API 中转站

#### [PackyAPI](https://www.packyapi.com/register?aff=sIjX)

PackyAPI 当时支持人民币充值，也提供了 Claude Code、Codex、Gemini CLI 等工具的接入教程。准备使用时，先确认该服务是否支持你要用的模型，以及能否兼容当前工具版本。

**请求经过哪些服务：**

你的应用 → PackyAPI 中转服务 → 它所连接的模型渠道 → 返回结果。

这意味着提示词和请求里的其他内容都会经过第三方中转。接入前先看清服务商怎样保存日志、使用数据，再决定哪些个人、公司或客户资料可以发给它。页面上的模型和渠道名称，也不能代替对实际来源和官方接口兼容性的核实。

**当时的计费方式和优惠：**

- 当时记录的充值比例为“1 元人民币 = 1 美元额度”。这里的“美元额度”是该中转平台的内部计费单位，不是货币兑换，也不是 OpenAI 或 Anthropic 官方账户的美元余额。
- 记录中部分分组最低“0.2 折”。一次调用究竟花多少钱，要一起看模型的输入、输出价格、分组倍率和其他计费规则，不能只看充值比例或最低折扣。
- 记录中的活动为新注册赠送 `$1` 体验额度、首次充值 `9 折`。是否仍有活动、是否需要优惠码、赠额期限及适用范围，请以当前页面和结算条件为准。

“分组”是平台用来区分渠道或计费规则的分类，具体含义由平台定义，并不一定代表不同模型。此前记录有超过 27 个分组，涉及 Claude、OpenAI Codex、Gemini、Azure GPT，以及“官方 / AWS / AWS-Q”等渠道标签；数量、标签含义与实际可用模型都需查当前说明。
